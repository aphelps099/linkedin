# Homepage Futura fonts

- `futura-extra-black-bt.woff`: lossless WOFF conversion of `fonts/Futura Extra Black font.ttf` from `aphelps099/zebs`, commit `407ca1c3b3b12c11906b8f1772e11d562e152e45`. Original family/full name: Futura / Futura Extra Black BT. CSS weight 900.
- `futura-round-bold.woff2`: the user's uploaded `font.woff2`, used unchanged. Original family/style: Futura Round / Bold. CSS weight 700.

The homepage stylesheet scopes Extra Black to display headings and Round Bold to navigation text. The approved vector logo and custom iPod headline retain their original artwork.
